# GenPark SemVer Dependency Resolver Agent

## Description
Semantic Versioning 2.0.0 range matcher and dependency tree resolver for multi-agent toolkits and plugins.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery, MCP.Directory
